# Cattylogue

## Introduction

This is just a small organisation so that I can group together the repositories for my personal "Cattylogue" project.
Cattylogue is a system which allows you to create catalogues of items such as CDs, DVDs etc.
Users can create catalogues and invite others users to view what is visible inside of them.

This was created because my family has a very unorganised collection of different pieces of media, and I wanted to practice different programming tools and techniques to see how we could organise everything.
